# Data and code availability

## Data

The study's retained point-level measurements, statistical results, motif definitions, atlas visualization coordinates, reference figures and two real-cell demonstrations are available on [Zenodo](https://zenodo.org/records/24302450), DOI [10.5281/zenodo.24302450](https://doi.org/10.5281/zenodo.24302450).

The deposit is licensed under [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/). Uses outside the license's permissions require authorization from the relevant institutional rightsholder(s). Complete raw acquisitions and all inputs needed to refit the atlases are not included; the dataset README describes the available inputs.

## Code

The CBeA code is maintained at [github.com/YNCris/CBeA](https://github.com/YNCris/CBeA). The repository currently requires owner-authorized access. It contains the compiled Fourier/motion feature core, Python interfaces, numerical validation and statistical reproduction scripts. The repository's Git history identifies the exact code snapshot.

Original software is provided under [PolyForm Noncommercial 1.0.0](LICENSE). The author-retained core source and build records are available for institutional or editorial review by arrangement. Contact Songlin Wang (slwang@ccmu.edu.cn) or Mo Chen (chenm7@sustech.edu.cn) to arrange access or route commercial-license inquiries to the relevant institution.

Third-party software retains its original terms; see [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). The Zenodo DOI identifies the dataset, not the software.
