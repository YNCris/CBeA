# Data and code availability wording

Current status (2026-11-17): the dataset is publicly deposited on Zenodo under CC BY-NC 4.0. The companion code remains in the private repository https://github.com/YNCris/CBeA under PolyForm Noncommercial 1.0.0.

## Data availability

The complete retained derived point-level measurements and statistical outputs supporting the quantitative analyses are available at [Zenodo](https://zenodo.org/records/24302450), dataset version 0.1.0-rc2, DOI [10.5281/zenodo.24302450](https://doi.org/10.5281/zenodo.24302450). The deposit includes a minimal microscopy/contour/trajectory demonstration for each cell model, motif definitions, frozen atlas visualization coordinates, and reference figure exports. It does not include complete raw acquisitions or every input required to refit the full atlases. See the dataset README for precise scope.

The data license is [Creative Commons Attribution-NonCommercial 4.0 International (CC BY-NC 4.0)](https://creativecommons.org/licenses/by-nc/4.0/). Uses outside its permissions require separate authorization from the relevant rightsholder(s). Separately identified third-party rights remain unchanged.

The all-versions DOI [10.5281/zenodo.24302449](https://doi.org/10.5281/zenodo.24302449) resolves to the latest dataset version. Cite the version-specific DOI above to identify the data accompanying this release.

## Code availability

The CBeA reproduction package is held in the [private GitHub repository](https://github.com/YNCris/CBeA); access requires owner authorization. Software version 0.1.0-rc2 is a submission candidate, and no public software release or software DOI is claimed. The Zenodo DOIs above identify the dataset.

The original software is licensed under PolyForm Noncommercial License 1.0.0. It contains a Windows x64 CPython 3.10 compiled implementation of the original Fourier/motion features and inspectable scripts for derived statistical replay. Uses outside that license's permissions require separate authorization from the relevant institutional rightsholder(s). The license's provisions for the listed noncommercial organizations remain unchanged. Third-party segmentation, tracking, ACA/DTAK, and MATLAB components are obtained separately under their own licenses. This package is partially source-available, with a compiled core.

## For editorial review

The author-private source/build/provenance bundle is retained separately. Describe reviewer access arrangements only once agreed. Its existence does not imply public end-to-end acquisition-to-atlas reproduction.
